# Pipkite logo

`pipkite-brand-board.png` is the original design. Everything else is built from it as clean vectors.

| Folder | What's in it |
|---|---|
| `svg/` | Masters. Symbol (color, white, black), app icon, full logo (on dark, on light, white, black), wordmark |
| `png/app-icon/` | App icon tile: 16, 20, 24, 32, 40, 48, 64, 128, 256, 512, 1024 px |
| `png/symbol/` | Kite only, transparent: 64 to 1024 px |
| `png/logo/` | Full logo, transparent: 600, 1200, 2400 px wide |
| `windows/pipkite.ico` | Windows icon (16 to 256 px), used by the app and installer |
| `web/` | favicon (svg + ico), apple-touch-icon 180, icons 192 / 512, maskable 512 (copied to `frontend/public`) |
| `social/` | GitHub social preview 1280x640, profile picture 640x640 |

Colors: blue `#2F6FDE`, purple `#A78BFA`, dark `#0B0D11`. Font: Poppins Bold (outlined in the SVGs).

Use "on dark" on dark backgrounds and "on light" on light ones. Keep some empty space around the logo, and
don't stretch, recolor or add effects to it.
